# Agent Mail

[English](README.md) | [简体中文](README.zh-CN.md)

一个运行于 [OctoSense](https://github.com/OctoSense-org/OctoSense) 的智能邮件应用，
具备 AI 能力。基于 `mail` 宿主服务构建——应用永远看不到你的密码。

## 功能

- **读取与管理邮件** — 收件箱、文件夹、撰写、回复、发送
- **AI 总结、待办与安全提示** — 主动点击 AI 总结后，提取只属于当前用户且有原文依据的待办，并保守识别钓鱼邮件、诈骗请求和可疑链接；普通私人邮件与广告不会仅凭类型被标记为风险
- **对话确认加入待办** — 总结展示待办建议后询问是否加入 AgentMail 待办；回复“可以”或“全部加入”可批量添加，也可指定部分事项。拒绝时保留建议，已加入的事项不会重复添加；日历日程单独确认
- **发件人订阅与精读** — 在邮件详情二次确认订阅／取消订阅；账号侧栏「笔记」下方打开订阅摘要卡片、发件人来信列表和订阅范围问答。选择来源与关注主题，生成含来源依据、正文链接、跨邮件新闻合并及同范围上一期对比的简报；支持稍后阅读和逐级返回
- **宿主保管凭证** — 在设备自带的面板上登录；密码保存在平台密钥链中
- **离线优先** — 助手是可选功能；即使不可用，所有界面仍正常工作

订阅范围为宿主已经同步到设备的来信，跨文件夹分页归集并合并相同副本，
不会搬动原邮件或更改发送方的邮件列表订阅。应用打开期间每 90 秒尝试刷新；
应用关闭后不在后台运行。每期最多读取 12 封未入期邮件、每封前 8,000 字节，
截取与读取失败会明确提示；问答覆盖最近最多 12 封。来源链接仅取自已读取正文，
不抓取网页。服务器上未同步的历史与 HTML 中未出现在正文的链接不保证可用。
关注主题留空表示未订阅主题，不会默认关注全部，也不会调用 AI 生成简报；
已确认的发件人订阅保留。新邮件同步失败时仍可使用已同步内容，显示独立警告，
不会关闭 TLS 证书校验或删除订阅。

## 目录结构

```text
bundle/
  manifest.json     id: agent-mail, 权限: storage + mail + octos.*
  listing.json      商店文案（发布者信息为占位符——提交前请替换）
  main.splash       主程序
  assets/icon.svg   图标
```

#（mail、账号和助手均可使用）
